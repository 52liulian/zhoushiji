# 周食记 · 一周食谱

学校食堂一周食谱管理工具：纯前端网页应用，**零服务器、零依赖**，数据自动保存到浏览器 IndexedDB。支持周次管理、日期联动、菜品库、拖拽排餐、均衡检查、导出 Excel。

## ✨ 核心功能

| 功能          | 说明                                         |
| ------------- | -------------------------------------------- |
| 📅 周次联动   | 选择周次 → 日期自动回填；日期区间可手动修改以适应调休，按实际天数渲染、超 5 天自动续行且槽位用实际星期名（周六→星期六、周日→星期日）互不绑定，自定义设置自动保留 |
| 🍽 菜品库     | 分类管理 + 菜品增删改（配菜分行输入）        |
| 🖱 拖拽排餐   | 菜品可在任意餐格间拖拽移动                   |
| 📊 均衡检查   | 荤素搭配智能提示                             |
| 📥 导出 Excel | 精确列宽/页边距/样式，可直接打印             |
| 📋 智能排版   | 有配菜的菜独占一行，无配菜两两顿号连接，汤粥单独一行 |
| � 日期列     | 左侧星期列上方同步显示对应日期（如「10月8日」），随开始日期逐日递增，调休跨周末自动正确显示，导出 Excel 同步生效 |
| � 自动保存   | 所有改动写入 IndexedDB，刷新即恢复           |

## 🔧 自定义

- **修改学校名**：页面顶部输入框直接改，自动保存
- **调休改日期**：直接改工具栏「开始/结束」日期即可调整当前周区间（结束早于开始时自动按 1 天处理）。表格按实际天数渲染：少于 5 天不显示多余的空行/空星期，超过 5 天自动续行且第 6 天起槽位用实际星期名（周六→「星期六」、周日→「星期日」，互不绑定、可自由设置），切换周次后自定义区间仍保留，导出 Excel 同步生效
- **日期列显示**：左侧星期列上方自动同步显示对应日期（格式「M月D日」，如「10月8日」），日期随开始日期逐日递增；调休周跨周末（周四 → 周一）时日期与星期一一对应正确显示；无开始日期的旧数据回退为仅显示星期
- **菜品库**：点「🍽 菜品库」→ 添加/编辑/删除菜品和分类
- **排餐**：点餐格 ➕ 加菜、✕ 删菜，或直接拖拽菜品到目标餐格
- **数据存储**：浏览器 IndexedDB（数据库名 `zhoushiji`），无需后端
