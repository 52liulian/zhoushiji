# 周食记 · 一周食谱

学校食堂一周食谱管理工具：纯前端网页应用，**零服务器、零依赖**，数据自动保存到浏览器 IndexedDB。支持周次管理、日期联动、菜品库、拖拽排餐、均衡检查、导出 Excel。

## ✨ 核心功能

| 功能          | 说明                                         |
| ------------- | -------------------------------------------- |
| 📅 周次联动   | 选择周次 → 日期自动调整；改日期 → 反选周次 |
| 🍽 菜品库     | 分类管理 + 菜品增删改（配菜分行输入）        |
| 🖱 拖拽排餐   | 菜品可在任意餐格间拖拽移动                   |
| 📊 均衡检查   | 荤素搭配智能提示                             |
| 📥 导出 Excel | 精确列宽/页边距/样式，可直接打印             |
| 💾 自动保存   | 所有改动写入 IndexedDB，刷新即恢复           |

## 🚀 使用方式

**直接双击 `index.html`** 即可（Chrome / Edge / 任何现代浏览器）。

也可部署到 GitHub Pages，在线访问。

## 🔧 自定义

- **修改学校名**：页面顶部输入框直接改，自动保存
- **菜品库**：点「🍽 菜品库」→ 添加/编辑/删除菜品和分类
- **排餐**：点餐格 ➕ 加菜、✕ 删菜，或直接拖拽菜品到目标餐格
- **数据存储**：浏览器 IndexedDB（数据库名 `zhoushiji`），无需后端
